# VICOPU: Política de Privacidade

O VICOPU roda inteiramente no computador do usuário. Não existe servidor do VICOPU.

- **Dados do TikTok/YouTube:** os tokens de acesso ficam salvos só no computador do usuário (pasta `dados/credenciais`) e são usados apenas para enviar os vídeos que o próprio usuário aprovou e ler as estatísticas desses vídeos.
- **Nada é vendido, compartilhado ou enviado** para terceiros além das próprias plataformas (TikTok, YouTube) e, quando o usuário ativa, do serviço de IA usado para sugerir títulos.
- **Escopos usados no TikTok:** `user.info.basic` (identificar a conta) e `video.upload` / `video.publish` (enviar os vídeos).
- **Como apagar:** apague a pasta `dados/credenciais` e revogue o acesso do app nas configurações da sua conta do TikTok/Google.
