# VICOPU: Termos de Uso

O VICOPU é uma ferramenta pessoal, de código aberto, que roda no computador do próprio usuário para cortar momentos de lives e enviar os vídeos para as contas do próprio usuário (YouTube e TikTok).

- O VICOPU só publica nas contas que o próprio usuário autorizou, e só quando o usuário aprova cada vídeo.
- O usuário é responsável pelo conteúdo que publica e por respeitar as regras de cada plataforma e os direitos dos criadores das lives (o VICOPU coloca o crédito do streamer em cada vídeo).
- A ferramenta é fornecida "como está", sem garantias.
- O usuário pode revogar o acesso a qualquer momento nas configurações da própria conta (YouTube/Google ou TikTok).
